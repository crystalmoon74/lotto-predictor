# 로또 6/45 번호 예측기

1회부터 최신 회차까지의 당첨번호로 학습한 모델이 매주 토요일 추첨 전에 이번 회차 추천 번호 5세트를 제안하는 웹사이트입니다.

**사이트:** https://crystalmoon74.github.io/lotto-predictor/

## 예측 모델

1. **번호별 점수**: 장기 출현 빈도 + 최근 빈도(반감기 26회 지수 감쇠) + 미출현 간격 + 직전 회차 이월 경향의 가중합
2. **후보 생성**: 점수에 비례한 확률로 6,000개 조합 생성 (회차 번호를 시드로 사용해 같은 주에는 같은 결과)
3. **패턴 필터**: 과거 당첨 조합 분포 기반 (합계 범위, 홀짝·고저, 연속번호, 끝수·번호대 다양성, AC값, 기존 1등 조합 제외)
4. **최종 선택**: 번호 점수 + 동반 출현 점수 + 분포 적합도가 높고 서로 3개 이상 겹치지 않는 5세트

사이트에서 가중치 조정, 지난 회차 비교, 최근 52회 백테스트를 볼 수 있습니다.

## 실행

- **GitHub Pages**: `main`에 push하면 `.github/workflows/pages.yml`이 최신 당첨번호를 받아 `public/`을 배포합니다. 매주 일요일 12:00(KST)에도 자동 재배포됩니다.
- **로컬**: `npm start` → http://localhost:3000 (Node 18+, 외부 패키지 없음)
