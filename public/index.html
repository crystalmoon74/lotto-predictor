    각 요소의 비중을 바꾸면 추천 번호가 다시 계산됩니다.

    번호별 모델 점수

    백테스트 (최근 52회)

    각 회차마다 그 이전 데이터만으로 학습해 5세트를 예측하고, 실제 당첨번호와 비교했습니다. 위에서 가중치를 바꾸면 그 가중치로 다시 계산됩니다.

    계산 중…

    예측 모델은 이렇게 동작합니다

    1. 번호 점수 계산 — 1회부터 최신 회차까지의 당첨번호로 장기 출현 빈도, 최근 출현 빈도(반감기 26회 지수 감쇠), 미출현 간격(기대 간격 7.5회 대비), 직전 회차 이월 경향을 계산해 가중합합니다.
    2. 후보 조합 생성 — 번호 점수에 비례한 확률로 6,000개 후보 조합을 뽑습니다. 회차 번호를 난수 시드로 써서 같은 주에는 항상 같은 결과가 나옵니다.
    3. 패턴 필터 — 과거 당첨 조합 분포에서 학습한 조건(합계 하위·상위 10% 제외, 홀짝·고저 6:0 제외, 3개 이상 이어지는 연속번호(예: 16·17·18) 제외, 끝수·번호대 다양성, AC값, 기존 1등 조합 제외)을 통과한 조합만 남깁니다.
    4. 최종 선택 — 번호 점수, 동반 출현(pair) 점수, 합계·홀짝 적합도로 조합을 평가하고, 서로 3개 이상 겹치지 않는 상위 5세트를 고릅니다.
